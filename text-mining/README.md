# Text Mining (IST 736)

Coursework from IST 736 Text Mining at Syracuse University, covering sentiment
analysis, text vectorization, and text classification.

## Contents

| Notebook | Topic |
|---|---|
| `ZURMAN_HW1.ipynb` | **Public sentiment toward AI** — tokenization, then sentiment scoring with both VADER and TextBlob on a Kaggle tweet dataset, comparing the two scorers. |
| `ZURMAN_HW2.ipynb` | **Vectorization report** — preprocessing and stemming (Porter), then comparing `CountVectorizer` against `TfidfVectorizer` output and arguing for the better choice. |
| `ZURMAN_HW3.ipynb` | **Classifying deceptive vs. truthful hotel reviews** — TF-IDF features into logistic regression, evaluated with accuracy and a full classification report. |

## Techniques

Tokenization · stopword removal · Porter stemming · VADER · TextBlob ·
bag-of-words · TF-IDF · logistic regression · word clouds

## Stack

Python · nltk · scikit-learn · vaderSentiment · TextBlob · pandas ·
matplotlib · wordcloud · kagglehub
